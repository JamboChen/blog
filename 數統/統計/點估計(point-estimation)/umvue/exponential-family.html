指數族與 UMVUE 應用

指數族定義

Definition: Exponential Family

設 X~∼iidf(x~;θ),θ∈Ω⊆Rr

若對於所有 x~,θ，有 f(x~;θ)=c(θ)exp(∑i=1k​Qi​(θ)Ti​(x~))h(x~)

並且滿足 X={x~:f(x~;θ)>0}⊥θ,c(θ)>0,h(x~)>0

則稱 f(x~;θ) 為 k-parameter exponential family

指數部分需要有 k 個項目組成，那麼 f(x~;θ) 就是一個 k-parameter exponential family。

指數族的完備性定理

Exponential Family Completeness Theorem

設 X~∼iidf(x~;θ),θ∈Ω⊆Rr，且 f(x~;θ) 屬於 k-parameter exponential family，其中

B≜{(Q1​(θ),⋯,Qk​(θ)):θ∈Ω}⊂Rk

若 B˚=∅（內點集非空），即 dim(B)=k，則 T(X~)=(T1​(X~),⋯,Tk​(X~)) 是 θ 的 sufficient 且 complete 統計量。

這個定理是本頁所有範例的共同工具：只要能把 pdf 湊成指數族形式並驗證 B˚=∅，就同時得到充分性與完備性，接著就能用 Lehmann-Scheffe 定理 求 UMVUE。

指數族的應用實例

1. Bernoulli 分布

例子：X1​,⋯,Xn​∼iidB(1,p),p∈(0,1)

f(\tilde{x};p) &= p^{\sum x_i}(1-p)^{n-\sum x_i}, \quad x_i = 0,1 \\ &= (1-p)^n \cdot \left(\frac{p}{1-p}\right)^{\sum x_i} \\ &= (1-p)^n \exp\left[\sum x_i \ln\left(\frac{p}{1-p}\right)\right] \\ &= c(p)\exp(Q(p)T(\tilde{x}))h(\tilde{x}) \end{align}$$ 其中 $\mathcal{X} = \{\tilde{x} : x_i = 0 \text{ or } 1, \forall i\} \perp p$ 因此 $f(\tilde{x};p)$ 屬於 1-parameter exponential family，其中： $$B = \{Q(p) : p \in \Omega\} = \left\{\ln\left(\frac{p}{1-p}\right) : p \in (0,1)\right\} = (-\infty, \infty) = \mathbb{R}^1$$ 故 $\mathring{B} \neq \emptyset$，所以 $T(\tilde{X}) = \sum X_i$ 是 $p$ 的 sufficient 且 complete 統計量。 > [!example] UMVUE 計算：$\eta(p) = p$ > > $T \sim B(n,p)$，$E_p[T] = np \Rightarrow E_p\left[\frac{T}{n}\right] = p$ > > 所以 $\frac{T}{n} = \bar{X}$ 是 $p$ 的 UMVUE。 > [!example] UMVUE 計算：$\eta(p) = p(1-p)$ > > **目標**：求 $\eta(p) = p(1-p) = P(X_1 = 1, X_2 = 0)$ 的 UMVUE > > 注意到 $\eta(p) = E_p[I(X_1 = 1, X_2 = 0)]$ > > 因此 $\eta(p)$ 的 UMVUE 為： > $$\begin{align} > E[I(X_1 = 1, X_2 = 0)|T] &= P(X_1 = 1, X_2 = 0|T) \\ > &= \frac{P(X_1 = 1, X_2 = 0, T = t)}{P(T = t)} \\ > &= \frac{P(X_1 = 1)P(X_2 = 0)P\left(\sum_{i=3}^n X_i = t-1\right)}{P(T = t)} \\ > &= \frac{p(1-p)\binom{n-2}{t-1}p^{t-1}(1-p)^{n-1-(t-1)}}{\binom{n}{t}p^t(1-p)^{n-t}} \\ > &= \frac{\binom{n-2}{t-1}}{\binom{n}{t}} \\ > &= \frac{t(n-t)}{n(n-1)} > \end{align}$$ ### 2. Poisson 分布 **例子**：$X_1, \cdots, X_n \stackrel{\text{iid}}{\sim} P(\lambda), \lambda > 0$ $$\begin{align} f(\tilde{x};\lambda) &= \prod_{i=1}^n \frac{e^{-\lambda}\lambda^{x_i}}{x_i!} \\ &= e^{-n\lambda}\lambda^{\sum x_i}\frac{1}{\prod x_i!} \\ &= c(\lambda)\exp\left(\sum x_i \ln\lambda\right)h(\tilde{x}) \end{align}$$ 這屬於 1-parameter exponential family，其中 $\mathcal{X} = \{\tilde{x} : x_i \in \mathbb{N}\} \perp \lambda$ $$B = \{\ln\lambda : \lambda > 0\} = (-\infty, \infty) \Rightarrow \mathring{B} \neq \emptyset$$ 因此 $T = \sum X_i$ 是 $\lambda$ 的 sufficient 且 complete 統計量。 > [!example] UMVUE 計算：$\eta(\lambda) = \lambda$ > > $T \sim P(n\lambda)$，故 $E(T) = n\lambda$，因此 $E\left(\frac{T}{n}\right) = \lambda$ > > 所以 $\frac{T}{n}$ 是 $\lambda$ 的 UMVUE。 > [!example] UMVUE 計算：$\eta(\lambda) = e^{-2\lambda}\lambda^3$ > > 觀察到： > $$\eta(\lambda) = e^{-2\lambda}\lambda^3 = 3! \cdot P(X_1 = 3, X_2 = 0) = E[6I(X_1 = 3, X_2 = 0)]$$ > > 因此 $\eta(\lambda)$ 的 UMVUE 為： > $$6E[I(X_1 = 3, X_2 = 0)|T] = 6P(X_1 = 3, X_2 = 0|T)$$ ## 正態分布的 UMVUE ### 情況 1：$\sigma^2 = \sigma_0^2$ 已知 設 $X_1, \cdots, X_n \stackrel{\text{iid}}{\sim} N(\mu, \sigma_0^2)$ $$f(\tilde{x};\mu) = \left(\frac{1}{\sqrt{2\pi\sigma_0^2}}\right)^n e^{-\frac{n\mu^2}{2\sigma_0^2}} \exp\left(\frac{\mu}{\sigma_0^2}\sum x_i\right) e^{-\frac{1}{2\sigma_0^2}\sum x_i^2}$$ 這屬於 1-parameter exponential family，其中 $\mathcal{X} = \mathbb{R}^n \perp \mu$ $$B = \left\{\frac{\mu}{\sigma_0^2} : \mu \in \mathbb{R}\right\} = \mathbb{R} \Rightarrow \mathring{B} \neq \emptyset$$ 因此 $T = \sum X_i$ 是 $\mu$ 的 sufficient 且 complete 統計量（等價地，$\bar{X}$ 也是）。 > [!example] UMVUE 計算 > > 1. **$\eta(\mu) = \mu$**：$\bar{X} \sim N\left(\mu, \frac{\sigma_0^2}{n}\right)$，$E(\bar{X}) = \mu$，因此 $\bar{X}$ 是 $\mu$ 的 UMVUE > 2. **$\eta(\mu) = \mu^2$**：$\text{Var}(\bar{X}) = \frac{\sigma_0^2}{n}$，故 $E(\bar{X}^2) = \mu^2 + \frac{\sigma_0^2}{n}$，因此 $\bar{X}^2 - \frac{\sigma_0^2}{n}$ 是 $\mu^2$ 的 UMVUE ### 情況 2：$\mu = \mu_0$ 已知 設 $X_1, \cdots, X_n \stackrel{\text{iid}}{\sim} N(\mu_0, \sigma^2)$ $$f(\tilde{x};\sigma^2) = \left(\frac{1}{\sqrt{2\pi\sigma^2}}\right)^n \exp\left(-\frac{1}{2\sigma^2}\sum(x_i - \mu_0)^2\right)$$ 這屬於 1-parameter exponential family，其中： $$B = \left\{-\frac{1}{2\sigma^2} : \sigma^2 > 0\right\} = (-\infty, 0) \Rightarrow \mathring{B} \neq \emptyset$$ 因此 $T = \sum(X_i - \mu_0)^2$ 是 $\sigma^2$ 的 sufficient 且 complete 統計量。 > [!note] 重要性質 > > 注意到 $\sum\left(\frac{X_i - \mu_0}{\sigma}\right)^2 \sim \chi^2_n$，$E(\chi^2_n) = n$ > > 即 $\frac{T}{\sigma^2} \sim \chi^2_n$，故 $E(T) = \sigma^2 \cdot n$，因此 $E\left(\frac{T}{n}\right) = \sigma^2$ > [!example] UMVUE 計算 > > 1. **$\eta(\sigma^2) = \sigma^2$**：$\frac{1}{n}\sum(X_i - \mu_0)^2$ 是 $\sigma^2$ 的 UMVUE > 2. **$\eta(\sigma^2) = \sigma = \sqrt{\sigma^2}$**：設 $Y \sim \chi^2_n$，則 $E(\sqrt{Y}) = \sqrt{2}\dfrac{\Gamma\left(\frac{n+1}{2}\right)}{\Gamma\left(\frac{n}{2}\right)} \triangleq C_n$，因此 $\dfrac{\sqrt{T} \cdot \Gamma\left(\frac{n}{2}\right)}{\sqrt{2} \cdot \Gamma\left(\frac{n+1}{2}\right)}$ 是 $\sigma$ 的 UMVUE ### 情況 3：$\mu, \sigma^2$ 皆未知 設 $X_1, \cdots, X_n \stackrel{\text{iid}}{\sim} N(\mu, \sigma^2)$ $$\begin{align} f(\tilde{x};\mu,\sigma^2) &= \left(\frac{1}{\sqrt{2\pi\sigma^2}}\right)^n e^{-\frac{n\mu^2}{2\sigma^2}} \\ &\quad \times \exp\left(-\frac{1}{2\sigma^2}\sum x_i^2 + \frac{\mu}{\sigma^2}\sum x_i\right) \end{align}$$ 這屬於 2-parameter exponential family，其中： $$B = \left\{\left(\frac{\mu}{\sigma^2}, -\frac{1}{2\sigma^2}\right) : (\mu,\sigma^2) \in \mathbb{R} \times (0,\infty)\right\} = \mathbb{R} \times (-\infty, 0)$$ 故 $\mathring{B} \neq \emptyset$，因此 $T^* = \left(\sum X_i, \sum X_i^2\right)$ 是 $(\mu, \sigma^2)$ 的 sufficient 且 complete 統計量。 等價地，$T = (\bar{X}, S^2)$ 是 $(\mu, \sigma^2)$ 的 sufficient 且 complete 統計量。 由 [[basu|Basu 定理]]，$\bar X$ 與 $S^2$ 相互獨立，這是以下 UMVUE 推導的關鍵。 > [!example] UMVUE 計算 > > 1. **$\eta(\mu, \sigma^2) = \mu$**：$\bar{X}$ 是 $\mu$ 的 UMVUE（與 $\sigma^2$ 已知時相同） > 2. **$\eta(\mu, \sigma^2) = \mu^2$**：$E(\bar{X}^2) = \text{Var}(\bar{X}) + (E\bar{X})^2 = \frac{\sigma^2}{n} + \mu^2$，$E(S^2) = \sigma^2$（因為 $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2_{n-1}$），因此 $\bar{X}^2 - \frac{S^2}{n}$ 是 $\mu^2$ 的 UMVUE > 3. **$\eta(\mu, \sigma^2) = \sigma^2$**：$S^2$ 是 $\sigma^2$ 的 UMVUE（與 $\mu$ 已知時不同！） > 4. **$\eta(\mu, \sigma^2) = \frac{\mu}{\sigma}$**：設 $Y \sim \chi^2_m$，則 $E\left(\frac{1}{\sqrt{Y}}\right) = \dfrac{\sqrt{2}\Gamma\left(\frac{m-1}{2}\right)}{\Gamma\left(\frac{m}{2}\right)} \triangleq a_m$，因此 $\dfrac{\bar{X}}{S} \cdot \dfrac{\sqrt{2}\Gamma\left(\frac{n-1}{2}\right)}{\sqrt{n-1}\Gamma\left(\frac{n-2}{2}\right)}$ 是 $\frac{\mu}{\sigma}$ 的 UMVUE ## 分布函數的 UMVUE > [!theorem] CDF 的 UMVUE > > 設 $X \sim f(x;\theta)$，$T = T(\tilde{X})$ 是 $\theta$ 的 sufficient 且 complete 統計量 > > 對於給定的 $x_0$，若我們關心 $\eta(\theta) = F(x_0;\theta) = P(X \leq x_0)$ > > 注意到 $F(x_0;\theta) = P(X \leq x_0) = E[I(X \leq x_0)]$ > > 因此 $F(x_0;\theta)$ 的 UMVUE 為： > $$E[I(X \leq x_0)|T] = P(X \leq x_0|T) = \delta(T)$$ > > 相應地，$f(x_0;\theta)$ 的 UMVUE 為： > $$\frac{\partial}{\partial x_0}\delta(T)$$ 這個結果告訴我們，即使是分布函數本身，也可以通過 sufficient 且 complete 統計量來找到其 UMVUE。
