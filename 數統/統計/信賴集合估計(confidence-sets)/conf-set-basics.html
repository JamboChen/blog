信賴集合估計基礎

動機。 點估計只給出單一數值，無法反映估計的不確定性；即使是 UMVUE，也幾乎必然 Pθ​(δ(X~)=η(θ))=0（連續分佈下）。因此我們改為估計一個「集合」，並要求這個集合以一定機率涵蓋真實參數。

我們有 n 個數據 X~=(X1​,⋯,Xn​)∼f(x~;θ)，θ∈Ω⊂Rr,r≥1，並且對 η(θ):Ω→Rm（通常 m=1）感興趣。

在數據 X~ 下，η(θ) 的集合估計是指在 Rm（=η(Ω)）中找到一個子集 C(X~)，使得：

∀θPθ​(η(θ)∈C(X~))=r∈[0,1]

當得到實際數據 X~=x~ 時，我們稱有 r 的信心使未知量 η(θ)∈C(x~)。因為數據確定後，η(θ) 是否落在 C(x~) 也是確定的，只是我們不知道。

範例：常態分佈均值的信賴區間

例子：X1​,⋯,Xn​∼iidN(μ,σ02​)，σ02​ 已知。

σ0​n​(Xˉ−μ)​∼N(0,1) ∀μ∈R1−α​=Pμ​(−zα/2​<σ0​n​(Xˉ−μ)​<zα/2​)=Pμ​(μ∈[Xˉ−n​zα/2​σ0​​, Xˉ+n​zα/2​σ0​​])​​

即 C(X~)=[Xˉ±n​zα/2​σ0​​] 滿足 Pμ​(μ∈C(X~))=1−α,∀μ。

涵蓋機率與評判標準

涵蓋機率

X~∼f(x~;θ)，θ 為真實參數，Pθ​(η(θ)∈C(X~)) 稱為 C(X~) 對 η(θ) 的涵蓋機率 (Coverage Probability)。

涵蓋機率當然越大越好，但若只追求這一點，取 C(X~)=η(Ω)（整個參數空間）就永遠是最好的——但這樣的區間毫無實用價值。因此我們還需要另一個標準：在涵蓋機率相同的情況下，希望 C(X~) 越「精確」越好，也就是要盡量排除錯誤的參數值。

我們計算 C(X~) 涵蓋到錯誤點的機率，稱為 false coverage probability：

Pθ​(η(θ∗)∈C(X~))∀θ∗=θ

這個機率越小越好；當 C(X~)=η(Ω) 時，false coverage probability 恆為 1。

備註

涵蓋機率與 false coverage probability 是互斥的：涵蓋機率最大化會導致 C(X~)=η(Ω)，false coverage probability 最小化會導致 C(X~)=η(∅)。因此需要先確保涵蓋機率至少達到某個信賴係數門檻，再盡可能讓 false coverage probability 最小化。

我們在意的「錯誤點」範圍依區間形式而異：

  • 雙邊區間 C(X~)=[L(X~),U(X~)]：在意所有 θ∗=θ
  • 單邊區間 C(X~)=[L(X~),∞)：只在意 η(θ∗)<η(θ) 的 θ∗
  • 單邊區間 C(X~)=(−∞,U(X~)]：只在意 η(θ∗)>η(θ) 的 θ∗

正式定義

信賴集合

C(X~) 是 η(θ) 的信賴集合：

  1. Pθ​(η(θ)∈C(X~))，∀θ∈Ω，稱為涵蓋機率。
  2. 若 θ∈Ωinf​Pθ​(η(θ)∈C(X~))=1−α，α∈[0,1]，則稱 C(X~) 為 η(θ) 的 1−α 信賴集合，1−α 稱為 C(X~) 的信賴係數。
  3. 1−α 信賴集合 C∗(X~) 稱為 uniformly most accurate (UMA) 1−α 信賴集合，若：
    1. θ∈Ωinf​Pθ​(η(θ)∈C∗(X~))=1−α
    2. 對所有 η(θ) 的 1−α 信賴集合 C(X~)，都有 Pθ​(η(θ∗)∈C∗(X~))≤Pθ​(η(θ∗)∈C(X~))，對所有相關的 θ∗=θ 成立
  4. 1−α 信賴集合 C(X~) 稱為無偏 (unbiased)，若 1−α≥Pθ​(η(θ∗)∈C(X~))，對所有相關的 θ∗=θ 成立
  5. 1−α 信賴集合 C∗(X~) 稱為 UMAU（uniformly most accurate unbiased），若 C∗(X~) 在所有無偏 1−α 信賴集合中是 UMA 的

範例：好的點估計不代表好的信賴區間

例子：X1​,⋯,Xn​∼iidN(μ,σ02​)，關心 μ。回顧 Xˉ 是 μ 的 UMVUE、MLE、MOME、minimax estimator，但 Pμ​(Xˉ=μ)=0,∀μ。

直覺想法：取固定寬度 C(X~)=[Xˉ±c]，c>0：

涵蓋機率​=Pμ​(μ∈[Xˉ±c])=2Φ(σ0​cn​​)−1∀μ​​

當 σ0​ 已知時（如 n=4,σ0​=1,c=1）可算出信賴係數 2Φ(2)−1=0.9544，也可反解 c=n​σ0​​zα/2​ 得到任意信賴係數 1−α。

但若 σ02​ 未知，θ=(μ,σ02​)：

信賴係數=θ∈Ωinf​Pθ​(μ∈[Xˉ±c])=σ0​>0inf​[2Φ(σ0​cn​​)−1]=0

因為 σ0​→∞ 時涵蓋機率趨近於 0。這說明「好的點估計 ± 固定常數」未必能得到有意義的信賴集合——必須把未知的變異程度也一併考慮進區間寬度中（見 Pivot 方法）。

範例：單邊信賴下界

例子：延續 σ02​ 已知的情況，取 C(X~)=[Xˉ−n​σ0​​zα​,∞)：

Pμ​(μ∈C(X~))=Pμ​(σ0​n​(Xˉ−μ)​≤zα​)=1−α

即 C(X~) 是 μ 的 1−α 信賴下界。驗證是否無偏：對 ∀μ∗<μ（我們不關心的錯誤方向）

Pμ​(μ∗∈C(X~))=P​Z≤zα​+<0σ0​n​​(μ∗−μ)​​​<1−α

因為 false coverage probability 小於信賴係數，符合無偏定義。是否為 UMA/UMAU，需要透過對應的假設檢定結果來判斷，見 Inverting Tests 方法。
