ANOVA

For regression model y=Xβ+ε,ε∼Nn​(0,σ2I)⟹y∼N(Xβ,σ2I)

Recall: LSE of β

動機。 想知道 y 的變化量有多少能被解釋變數 X 解釋掉，這需要把「總變異」拆成「模型解釋的變異」與「模型無法解釋的變異」兩部分，這就是變異數分析 (Analysis of Variance, ANOVA) 的核心想法。

SLR 下的直覺

在 SLR 中，Y^⊥e（因 Y^te=0）且 Yˉ1⊥e（因 ∑ei​=0），因此

Yˉ1⊥e=Y−Yˉ1⟹∣∣Y∣∣2=∣∣Yˉ1∣∣2+∣∣e∣∣2 ⟹∣∣Y−Yˉ1∣∣2=∣∣Y^−Yˉ1∣∣2+∣∣e∣∣2 i.e.SSTO∑(Yi​−Yˉ)2​​=SSR∑(Yi​^​−Yˉ)2​​+SSE∑(Yi​−Yi​^​)2​​
  • SSTO：數據 Y 與其均值 Yˉ 之間的差異，即數據的總變異量。
  • SSR：預測值 Y^ 與均值 Yˉ 之間的差異，代表模型解釋的變異量，越大代表模型解釋越多。
  • SSE：殘差平方和，代表模型無法解釋的變異量，越小越好。

Fundamental identity

dfSLRMLR​SSTOn−1n−1​===​SSR1k​+++​SSEn−2n−p=參數量(k+1)​​​
  • df: 自由度（degree of freedom）；k: 自變量的個數
E[SSE]=E[∑ei2​]=∑E[ei2​]E[ei​]=0∑σ2{ei​}=(n−p)σ2⟹E[n−pSSE​]=σ2

Definition

MSE≜n−pSSE​MSR≜kSSR​

MSE 是 σ2 的不偏估計，因此在迴歸中通常用 MSE 估計 σ2、用 MSE​ 估計 σ。一般地，若 σ2{∗}=σ2⋅c，定義 S2{∗}=MSE⋅c=σ2^{∗}，則 σ2{∗}S2{∗}​ 恆等於 σ2MSE​。

以上是 SLR 的特例，下面用矩陣形式推廣到 MLR，並給出 SSTO、SSR、SSE 各自的分佈。

SST​

SST​​=i=1∑n​(yi​−yˉ​)2=i=1∑n​yi2​−nyˉ​2=yty−n(n1​1ty)2, where 1=(1,…,1)t=yty−nyt(n1​1)(n1​1t)y=yt(In​−n1​11t)y​

where In​−n1​11t is symmetric, idempotent with rank=n−1.（冪等矩陣：rank = trace） Hence σ21​SST​∼χn−12​(δ),δ=σ21​βtXt(In​−n1​11t)Xβ Note: If ∀i,Xi​β are same, i.e. X 與 Y 沒有線性關係, δ=0,σ21​SST​∼χn−12​

SSE​

\begin{aligned} SS_E&=\sum_{i=1}^n(y_i-\hat{y}_i)^2=e^te\\ &=y^t(I-H)^t(I-H)y\\ &=y^t(I-H)y \end{aligned}$$ where $I-H$ is symmetric, idempotent with rank$=n-p$. Since $(I-H)X=0$, hence（[[線性代數/projection#Hat Matrix $H$|Hat Matrix 的補矩陣]]）$$\frac{1}{\sigma^2}SS_E\sim \chi^2_{n-p}$$ ### $SS_R$ $$\begin{aligned} SS_R&=SS_T-SS_E\\ &=y^t\left( I-\frac{1}{n}\mathbf{1}\mathbf{1}^t \right)y-y^t(I-H)y\\ &=y^t\left( H-\frac{1}{n}\mathbf{1}\mathbf{1}^t \right)y \end{aligned}$$ where $H-\frac{1}{n}\mathbf{1}\mathbf{1}^t$ is symmetric, idempotent with rank$=p-1=k$. Hence$$\frac{1}{\sigma^2}SS_R\sim\chi^2_k(\lambda),\quad \lambda=\frac{1}{\sigma^2}\beta^tX^t\left( H-\frac{1}{n}\mathbf{1}\mathbf{1}^t \right)X\beta$$ **Note**: If $\theta=E(y)=X\beta=\begin{bmatrix}1 & X_R\end{bmatrix}\begin{bmatrix}\beta_0\\\beta_R\end{bmatrix}=\beta_0\mathbf{1}+X_R\beta_R$, then $\lambda=\frac{1}{\sigma^2}\beta^t_R(X^t_cX^t_c)\beta_R$ with $\beta_R=(\beta_1,\dots,\beta_k)^t$ and $X_c=(X_{ij}-\bar{x}_i)$ 非中心卡方分佈的定義與這個二次型結論的完整證明，見 [[quadratic-form|Distribution of Quadratic Form]]。 --- Note that $$\begin{aligned} I&=(I-H)+\left( H-\frac{1}{n}\mathbf{1}\mathbf{1}^t \right)+\frac{1}{n}\mathbf{1}\mathbf{1^t}\\ \text{with rank }n&=(n-p)+(p-1)+1 \end{aligned}$$（[[線性代數/projection#ANOVA 中的平方和分解|三個正交投影矩陣的分解]]） Then, by [[mult-normal#Cochran's Theorem|Cochran's Theorem]]（[[線性代數/projection#Cochran's Theorem（平方和獨立性）|Cochran's Theorem]]）$SS_R\perp SS_E$ and $\delta=\lambda$. ## Test statistics

\frac{\frac{SS_R}{k}}{\frac{SS_E}{n-k-1}}=\frac{\frac{SS_R}{k\sigma^2}}{\frac{SS_E}{(n-k-1)\sigma^2}}\sim \frac{\chi^2_k(\lambda)/k}{\chi^2_{n-k-1}/(n-k-1)}\sim F_{k,n-k-1}(\lambda)

where $\lambda=\frac{1}{\sigma^2}\beta^t_R(X^t_cX^t_c)\beta_R$ with $\beta_R=(\beta_1,\dots,\beta_k)^t$ and $X_c=(X_{ij}-\bar{x}_i), p=k+1=$ number of unknown coefficients. 在 $H_0:\beta_1=\cdots=\beta_k=0$ 下 $\lambda=0$，此時 $E[\text{MSE}]=\sigma^2=E[\text{MSR}]\implies\text{MSR}/\text{MSE}$ 傾向接近 1；在 $H_1$ 下 $E[\text{MSR}]=\sigma^2+\frac{1}{p-1}\sum(\theta_i-\bar\theta)^2>\sigma^2=E[\text{MSE}]\implies\text{MSR}/\text{MSE}$ 傾向大於 1。因此檢定統計量取

F^\triangleq\frac{\text{MSR}}{\text{MSE}}\overset{H_0}{\sim}F_{k,n-k-1},\quad\text{reject }H_0\iff F^>F_{k,n-k-1,\alpha}

$\beta_0$ 通常不會被檢定，因為它是截距項，我們只關心解釋變數和反應變數之間的關係。 **Remark**：在 R 語言中，如果 `fm` 是我們的迴歸模型，可以使用 `anova(fm)` 得到 ANOVA 表： | Source | SS | df | | ------------ | -------- | -------- | | predictor1 | SSR1 | 1 | | predictor2 | SSR2 | 1 | | $\vdots$ | $\vdots$ | $\vdots$ | | predictor(p-1)| SSR(p-1) | 1 | | Error | SSE | n-p | R 會先對一個解釋變數做投影，扣除這個變數的影響後，再對下一個變數做投影，依此類推得到所有的 SSR。但因為解釋變數之間不一定正交，投影的順序可能會影響 SSR 的大小。因此構建模型時，會把認為比較重要的變數放在前面：比如 `lm(Y~X1+X2+X3)`，若認為 X1 對 Y 的影響最大，X2 次之，X3 最小，就把 X1 放在最前面。 ## ANOVA Model：定性解釋變數的特例 **動機。** 前面討論的迴歸模型中，解釋變數是連續型 (Quantitative)。若解釋變數是定性型 (Qualitative)，例如教育程度、血型，則不再談論「斜率」，而是比較不同類別（稱為*因素 (factor)*）下反應變數的平均是否相同，這種特例稱為 ANOVA Model。 ### One-way ANOVA Model *One-way* 指只在單個因素上分析。令第 $i$ 種類別下 $E(Y|X=i)=\mu_i,i=1,\cdots,k$（例如 $X$ 是血型，則 $i=$ A, B, AB, O），檢定

H_0:\text{ X 對 Y 無影響 }\iff H_0:\mu_1=\mu_2=\cdots=\mu_k

每個類別 $i$ 收集 $n_i$ 個樣本，共 $n=\sum n_i$ 個樣本，模型可寫成

Y_{ij}=\mu_i+\varepsilon_{ij},\quad i=1,\cdots,k,j=1,\cdots,n_i

矩陣形式：

Y_{n\times 1}=\underbrace{\begin{bmatrix} \mathbf{1}{n_1}&0&\cdots&0\ 0&\mathbf{1}{n_2}&\cdots&0\ \vdots&\vdots&\ddots&\vdots\ 0&0&\cdots&\mathbf{1}{n_k} \end{bmatrix}}{X} \underbrace{\begin{bmatrix}\mu_1\\mu_2\\vdots\\mu_k\end{bmatrix}}{\beta}+\varepsilon{n\times 1}

此時 $X^tX=\text{diag}(n_1,\cdots,n_k)$，$X^tY=(Y_{1\cdot},\cdots,Y_{k\cdot})^t$（$Y_{i\cdot}=\sum_j Y_{ij}$ 稱為 treatment totals），因此 LSE 恰為各組樣本平均：

\hat\mu=(X^tX)^{-1}X^tY=(\bar{Y}{1\cdot},\cdots,\bar{Y}{k\cdot})

$\hat Y_{ij}=\bar Y_{i\cdot},\forall i,j$，於是

\text{SSR}=\sum_i\sum_j(\bar{Y}{i\cdot}-\bar{Y}{\cdot\cdot})^2,\qquad \text{SSE}=\sum_i\sum_j(Y_{ij}-\bar{Y}_{i\cdot})

上式 $Y_{ij}=\mu_i+\varepsilon_{ij}=E(Y|X=i)+\varepsilon_{ij}$ 稱為 cell-mean model。令 $\mu=\frac{1}{k}\sum_i\mu_i$，$\tau_i=\mu_i-\mu$（$\sum_i\tau_i=0$），則

Y_{ij}=\mu+\tau_i+\varepsilon_{ij}

稱為 factor-effect model，$\tau_i$ 表示第 $i$ 組相對整體平均的偏移量。 ### Two-way ANOVA Model 兩個因素：A（$a$ 個水準）、B（$b$ 個水準），$Y=E(Y|A=i,B=j)+\varepsilon$。 - cell-mean model：$Y_{ijk}=\mu_{ij}+\varepsilon_{ijk}$，$\varepsilon_{ijk}\sim N(0,\sigma^2),k=1,\cdots,n_{ij}$ - factor-effect model：$Y_{ijk}=\mu+A_i+B_j+(\alpha\beta)_{ij}+\varepsilon_{ijk}$，其中 $(\alpha\beta)_{ij}$ 是 A、B 兩因素的交互作用項。
