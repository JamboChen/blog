線性模型

簡單線性模型 (Simple Linear Regression, SLR)

Definition

SLR：i=1,⋯,n，Xi​∈R1 且 E[εi​]=0

Yi​=β0​+β1​Xi​+εi​

E[Yi​∣X=Xi​]=E[β0​+β1​Xi​+εi​]=β0​+β1​Xi​=f(Xi​,β) 稱為回歸函數 (Regression Function)，其中 β=(β0​,β1​) 是未知參數。

複線性模型 (Multiple Linear Model, MLR)

複線性模型與 SLR 類似，但區別在於 Xi​=(Xi,1​,Xi,2​,⋯,Xi,k​)∈Rk 是多維向量，詳見 矩陣形式的迴歸模型。

Definition

MLR：i=1,⋯,n，Xi​∈Rk,k>1

Yi​=β0​+β1​Xi,1​+β2​Xi,2​+⋯+βk​Xi,k​+εi​

Note

  1. “線性”是指回歸函數 f(x;β) 中的參數都是線性的。
  2. 在一些非線性關係中，通過將 X 做一些變換，也可以用線性模型來分析。 e.g. Y=β0​+β1​sint+εx=sint​Y=β0​+β1​x+ε

我們拿到一組數據 (X1​,Y1​),⋯,(Xn​,Yn​)，假設這組數據是由一個線性模型產生的，即 Yi​=β0​+β1​Xi​+εi​，但不知道 β，並且 εi​ 是一個隨機變量。

目標是透過這組數據來估計 β，得到 β^​，然後透過 β^​ 得到預測值 Y^i​=f(Xi​;β^​)。

最小二乘估計 (Least Squares Estimation, LSE)

動機。 希望預測值 Y^i​ 與實際值 Yi​ 的差距越小越好，這需要一個衡量整體誤差大小的準則，因此定義：

Definition

殘差 (Residual)：ei​=Yi​−Y^i​

即 ∑i=1n​ei2​=∑i=1n​(Yi​−Y^i​)2 越小越好，這就是 最小二乘估計 (Least Squares Estimation, LSE) 的想法。

Definition

對於線性迴歸 Yi​=f(Xi​;β)+εi​，定義：

Q(β)=i=1∑n​(Yi​−E[Yi​])2=i=1∑n​(Yi​−f(Xi​;β))2

稱 b 是 β 的 LSE ⟺Q(b)=minβ​Q(β)

在 SLR 下，這是一個純量微分問題，可以直接對 β0​,β1​ 微分求解（矩陣形式的一般解法見 LSE 最小平方估計）：

Theorem

b0​b1​​=Yˉ−b1​Xˉ=∑i=1n​(Xi​−Xˉ)2∑i=1n​(Xi​−Xˉ)(Yi​−Yˉ)​=∑i=1n​(Xi​−Xˉ)2∑i=1n​Xi​(Yi​−Yˉ)​=∑i=1n​(Xi​−Xˉ)2∑i=1n​(Xi​−Xˉ)Yi​​​

⟹Y^i​=b0​+b1​Xi​=Yˉ−b1​Xˉ+b1​Xi​=Yˉ+b1​(Xi​−Xˉ)。

⟹ei​=Yi​−Y^i​=Yi​−Yˉ−b1​(Xi​−Xˉ)

Note：由上式可以直接驗證幾個性質：

  1. ∑i=1n​ei​=∑(Yi​−Yˉ−b1​(Xi​−Xˉ))=∑(Yi​−Yˉ)−b1​∑(Xi​−Xˉ)=0

  2. ∑i=1n​Y^i​=∑(Yˉ−b1​(Xi​−Xˉ))=nYˉ−b1​∑(Xi​−Xˉ)⟹n1​∑i=1n​Y^i​=Yˉ，i.e. 預測值的中心點是數據值的中心點。

  3. i=1∑n​(Xi​ei​)​=i=1∑n​[Xi​(Yi​−Yˉ−b1​(Xi​−Xˉ))]=i=1∑n​Xi​(Yi​−Yˉ)−b1​i=1∑n​Xi​(Xi​−Xˉ)=i=1∑n​Xi​(Yi​−Yˉ)−∑i=1n​(Xi​−Xˉ)2∑i=1n​Xi​(Yi​−Yˉ)​i=1∑n​(Xi​−Xˉ)2∵i=1∑n​Xi​(Xi​−Xˉ)=i=1∑n​(Xi​−Xˉ)2=0​

    將 X 和 e 寫成向量，i.e. X=(X1​,⋯,Xn​)t∈Rn,e=(e1​,⋯,en​)t∈Rn，則 Xte=0⟹X⊥e（垂直）。

  4. ∑i=1n​Y^i​ei​=∑i=1n​b0​ei​+b1​∑i=1n​Xi​ei​=0+0，令 Y^=(Y^1​,⋯,Y^n​)t∈Rn

    ⟹Y^te=0，i.e. Y^⊥e，since e=Y−Y^⟹Y^⊥Y−Y^

    所以預測值 Y^ 是 Y 的投影，這與矩陣形式下 y^​=Hy 是投影（見 LSE 的幾何解釋）的結論一致，SLR 只是其特例。

  5. 擬合的迴歸函數 Y^i​=Yˉ+b1​(Xi​−Xˉ) 通過點 (Xˉ,Yˉ)。
